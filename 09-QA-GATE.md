# Independent QA Gate
QA does not write the first draft.

## A Routing
PASS only if central entry recognised CanDo + worktops + SEO/content rebuild, SEO build capability ran and QA ran without user manually choosing it.

## B Product truth
FAIL on honeycomb/hexagonal Advance core, recycled-wood-fibre Advance claim, wrong series material, tap offered as orderable at launch, Essential flush-mounted sink, generic/vanaf price, invented Advance/Signature delivery, Signature 100% recycled/fully recyclable, or all worktops described as HPL/chipboard.

## C Page strategy
PASS only if owner retained, no extra competing owner proposed, page behaves as decision landing page, CTA uses retailer choice/configuration logic and primary outcome is outgoing retailer click.

## D Audience/brand
PASS only if copy is plain/helpful/confidence-building, mainly serves Do it together/Do it for me, promises no install service and invents no premium/luxury positioning.

## E Stramien
PASS only if supplied stramien is structural source, layout/design is not reinvented and old example copy is not treated as product truth.

## F Links
PASS only if every internal link is in link universe or live-verified, no known redirect/excluded route is knowingly used and sample URL is not fabricated.

## G Web delta-check
PASS only if owner opened, exact search `werkbladen op maat` run, at least three relevant results inspected where possible, date/URLs logged and live copy does not override internal truth.

## H Output
PASS only if source decision log, page brief, completed HTML using stramien, metadata, FAQ, internal links, unresolved facts and QA result are included.

Critical defect: any fabricated price, delivery time, material or publish action.
Gate result: `READY FOR HUMAN REVIEW` or `NOT READY`.


## I Retailer / route governance
PASS only if:
- no CanDo series story routes to FAB/no-name retailers;
- BE-FR uses Belgian retailer routes, not FR retailers;
- Bouwmaat is not consumer-facing while status is OPEN;
- Essential delivery is not copied to Advance/Signature;
- OPEN Advance/Signature retailer rollout is not presented as confirmed;
- every CTA destination is valid in both retailer matrix and locale sitemap/live check.

Any invented retailer-series availability = CRITICAL DEFECT.
