Read:

For locale links use ../../../07-LINKS/sitemap-*.csv. If a required sitemap is absent, mark that locale NOT READY instead of inventing URLs.

## Procedure
1. Confirm owner page, page job, source market and requested outputs.
2. Check the current owner page and current search context where web access is available.
3. Resolve source conflicts by ownership. Internal product truth and claims beat old/live/template copy.
4. Check retailer eligibility in `07-RETAILER-ROUTES.csv` before choosing CTA destinations.
5. Map the content jobs from `06-CONTENT-WORKBOOK.md` into the existing stramien. Keep structure, replace obsolete example copy.
6. Write answer-first, decision-led copy with natural search language.
7. Produce metadata, 4–6 useful FAQs, internal links, unresolved items and a source/decision log.
8. Do not approve your own final QA.

Never invent price, delivery time, maximum dimensions, retailer-series availability, sustainability claims or locale URLs. Never publish.
