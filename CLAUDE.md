# Deli Home SEO AI workspace

This repository is a shared AI workspace for Claude Code and GitHub Copilot. Treat it as a controlled marketing/content system, not as a generic coding project.

## Start every substantial task here
1. Read `00-ROOT.md`.
2. Classify the task and target market(s).
3. Load only the canonical files relevant to that task.
4. Use the specialist agent or skill when one matches.
5. Keep CONFIRMED, OPEN, VERIFY_LIVE and FORBIDDEN statuses intact.
6. Use live web research only for current/live information. Never let live copy overwrite newer internal product truth.
7. Never publish, update a CMS, send data externally or modify a business system during this benchmark.
